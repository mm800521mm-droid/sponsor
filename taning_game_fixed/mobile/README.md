# 裂隙余烬｜手机端入口

这是一个独立的手机网页应用入口，游戏本体仍使用上一级目录的 `../index.html`。

## 使用方式

1. 将整个 `taning_game_fixed` 文件夹部署到支持 HTTPS 的静态网站（例如 GitHub Pages）。
2. 在手机浏览器打开 `/taning_game_fixed/mobile/`。
3. 可通过浏览器菜单选择“添加到主屏幕”或“安装应用”（浏览器支持时）。
4. 从主屏幕打开后，游戏会在全屏 iframe 中运行。

## 注意

- 需要通过 HTTPS 或 localhost 提供页面，浏览器才允许 Service Worker 和 PWA 安装能力。
- Service Worker 目前缓存手机入口、清单文件和外壳；游戏本体及资源仍需网络加载。
- 这是游戏的手机入口，不是独立离线游戏包。
- 手机适配仍需在真实设备上测试触控、横竖屏和安全区域。
